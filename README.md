# CodeAlpha-Ecommerce-Analysis
Comparative E-Commerce Analysis: Amazon vs Flipkart vs Myntra using Data Visualization and Exploratory Data Analysis (EDA). This project analyzes 62,840+ product records to compare pricing, ratings, category performance, and platform-wise trends using Python, Pandas, Matplotlib, and Seaborn.
This project was completed as part of the CodeAlpha Data Science Internship (Task 3: Data Visualization).

The objective of this project is to perform Exploratory Data Analysis (EDA) and create meaningful visualizations by combining product data from Amazon, Flipkart, and Myntra. The analysis focuses on platform-wise product distribution, pricing strategies, customer ratings, category performance, and business insights.

Tools Used:
• Python
• Pandas
• NumPy
• Matplotlib
• Seaborn
• Jupyter Notebook

Dataset Size:
• 62,840+ records
• 3 E-commerce Platforms

Key Outcomes:
• 15+ Professional Visualizations
• Platform Comparison Analysis
• Price vs Rating Analysis
• Category Performance Analysis
• Business Insights and Recommendations
